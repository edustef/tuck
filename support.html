Tuck Help & Support

Add a card

Tap +. Scan the original card, import a clear photo or screenshot, or type its number. Choose the exact code format printed on the original card. Do not switch a barcode to QR just to make a number fit. Store presets are shortcuts; you can enter any custom store.

At checkout

Open a card and tap Show at checkout. Tuck raises screen brightness while the checkout screen is active, then restores your previous brightness. Keep the white space around the code visible. A cashier may also be able to enter the displayed card number.

A retailer won’t accept the code

Compare the saved number and format with the original. Some loyalty apps use rotating or app-only codes, coupons or activation steps. Use the official retailer app for those features. Tuck cannot recreate rotating credentials or bypass retailer rules. Keep the original card until you have confirmed acceptance.

Supported code formats

QR, Code 128, EAN-13, UPC-A (displayed as equivalent EAN-13), EAN-8, UPC-E, Code 39, Code 93, Interleaved 2 of 5, PDF417 and Aztec. Code 39 and Code 93 support their standard uppercase alphabet. Other formats or extended control-character payloads may require the original card.

No camera access

Enable Tuck’s camera permission in iPhone Settings. You can still add cards manually or use the system photo picker without camera permission. Crop screenshots to a single clear code before importing.

iCloud

Choose personal iCloud during onboarding or in Settings. Sign in to iCloud on each iPhone using the same Apple account. Check connectivity and available iCloud storage. Cards remain available locally while sync waits. Deletions sync too. Turning sync off leaves the existing iCloud copy intact. If you change your Apple account, verify which cards you want in that account before re-enabling sync.

Export, restore, delete

Settings → Export cards saves a readable JSON backup. Settings → Import a backup adds new card IDs without replacing existing cards. Keep exports private. You can delete individual cards from their menu or all cards in Settings. Enable sync first if you also want deletion to reach your synced iCloud copy.
